# Devin SWE-2 free short window

The free short-window limit is observed only from the bounded, recent-unwrapped pane text of a Devin worker. Scopefuel does not query Devin for this signal. It stores the latest live observation in its XDG cache directory at devin-free-limit.json, protected by a file lock and atomic replacement.

The current Devin provider result does not expose a stable account fingerprint, so the observer normally uses a hash of the current host name and Unix user id. If a local snapshot already contains an account-kind credential-free fingerprint, the observation uses that identity instead. The fallback is host-local and may not distinguish Devin accounts used by the same Unix user on that host. A later account-keyed record will not match the old host-user key.

The existing quota-share channel publishes provider quota snapshots to a remote document endpoint keyed by account fingerprint, and it publishes or reads only when an account-kind fingerprint is available. Devin currently supplies no stable account fingerprint, so quota-share cannot bind this pane observation to a Devin account; adding an observation record type alone would not make it safe to share. A credential-free Devin account identity and a typed observation writer and gate-time reader would both be needed for cross-host propagation. No network endpoint is added.

A live hold can be lifted without waiting for the reset: `scopefuel observe devin-free-limit --clear` removes the live record under the same file lock and atomic replacement as the writer, prints the removed record's reset, observed time, source, and rung (never the identity key or any credential material), and exits 0 even when there was nothing to clear. `--account-key KEY` clears the record stored under a different identity key instead of the current host-user or cached-account key; the stored keys are visible in the state file. The manual fallback is deleting the state file itself: `scopefuel/devin-free-limit.json` inside the XDG cache directory (`$XDG_CACHE_HOME/scopefuel/devin-free-limit.json`, or `~/.cache/scopefuel/devin-free-limit.json`).

Install order is scopefuel first, then agent-skills. The scopefuel commit that first accepts observe devin-free-limit is the minimum version required by the worker observer. An older scopefuel rejects the command; the agent-skills observer logs that failure and continues the job lifecycle.

The hold members are the six free SWE-2 spellings and, since hk 1729 r2, the two Fusion-Sol spellings devin-fusion-sol61 and devin-fusion-sol61-xhigh. Membership means a pane on that profile stalls when the free SWE-2 window is exhausted: a Fusion-Sol pane stopped on the free-limit notice instead of continuing with its Sol lead. free_window.FREE_PROFILES is the single membership source for both gate and recommend. Fusion-Sol still reads and gates on the codex pool, a held Fusion-Sol recommend row names codex as its provider, and Fusion-Sol never enters the SWE-2 model-scope or free-bucket path. The gate applies the hold only after normal admission has accepted one of these members. A role, subscription, measurement, policy, or ordinary quota refusal keeps its original reason, output, and exit code. Recommendations apply the hold only to rows that passed their normal candidacy checks; existing exclusions keep their original reason and structure. No-record and expired-record behavior remains unchanged.

Gate alternatives are not filtered for paid Devin or non-Devin profiles. Their existing alternative text may name a free SWE-2 rung or Fusion-Sol spelling covered by a live hold; that profile still receives its own gate refusal. Corrupt state is logged and ignored fail-open, including malformed JSON that exceeds Python's nesting or integer parsing limits. New observations with future observed times are rejected, and pre-existing future-dated records are ignored and pruned when a current observation is saved.

The oldest scopefuel commit accepting observe devin-free-limit is 99abef2b3b8636d06b04080b90b047dad79a0ec7. Accepting observations from all actual Devin profile UIDs, including paid profiles, requires 542a8c744b9e012b095ef345eff3501f8bfcddbc or newer. Observing and holding the two Fusion-Sol spellings requires the scopefuel PR 157 change (hk 1729), branch commit a762c2a56853a6af4fdab22087d6031e290af15c, or newer; older scopefuel does not know these profiles, so the observer logs the rejected observation and only the six free SWE-2 names are held.
